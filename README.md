## Kurulum

1. Bu paketin içindekileri GitHub E.log reposuna tek seferde yükle.
2. Google Cloud Shell aç.
3. Repo'yu klonla ve setup scriptini çalıştır:

```bash
git clone https://github.com/nnurallar-commits/E.log.git && cd E.log && bash setup-cloudshell.sh
```

Script OpenAI API anahtarını terminalde gizli şekilde bir kez ister. Anahtar GitHub dosyalarına yazılmaz.

Firebase Functions/Scheduler deploy sırasında Firebase billing planı isteyebilir. Bu Firebase'in sunucu tarafı özellikleri için gereken hesap ayarıdır.
