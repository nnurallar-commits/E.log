# E.log REPO HOTFIX

Düzeltilenler:
- Sekmeler ve butonlar yeniden temiz script ile bağlandı.
- Nöbet: 08:30'da başlar, ertesi gün 08:30'da biter.
- Aynı anda birden fazla nöbet günü seçilebilir.
- AI backend yoksa bile yerel akıllı cevap verir; sessiz kalmaz.
- Eroland + Anı gerçekten kaydeder.
- Anı / Plan / Yer filtreleri çalışır.
- Fotoğraf ve video seçilebilir; Firebase Storage'a yüklenir.
- Eroland kayıtlarına 1 ay, 6 ay, 1 yıl veya özel tarih hatırlatması eklenebilir.
- Aynı güne 4 emoji eklenebilir.
- 24 saat formatı.

GitHub repo köküne bu paketteki dosyaları yükle.
Not: Foto/video paylaşımının iki cihazda da çalışması için storage.rules Firebase'e deploy edilmelidir.
